# SpiritUp
SpiritUp es una aplicación móvil que impulsa el hábito R07 mediante reflexión diaria de la Biblia. Permite escribir notas, grabar audios y recibir recordatorios. Incluye racha, insignias y mascota que crece con el progreso. También muestra estadísticas para motivar constancia. Une fe y tecnología para fortalecer disciplina y crecimiento espiritual.
